## 2. What went well

- **A mock-up before any story.** The project lead decided the whole layout in one look; no rework of the design was needed during the epic.
- **Review found long-standing defects outside the story's scope:** the theme toggle had never switched dark mode (every `dark:` utility compiled to `prefers-color-scheme`); three scripts crashed when `localStorage` is blocked; Tailwind never compiled classes used only in JavaScript (the session-timeout and connection toasts were never positioned). All three are fixed with regression tests.
- **One element, two roles.** Making the sidebar and the drawer the same `<nav>` removed the second landmark and the hand-copied entry list the old bar had.

## 3. What did not go well

- **Focus on /catalog took two rounds.** The first fix for "a toggle must not disturb scanning" moved focus to the scan field after every toggle, which would have stolen it from the manual title form. **Lesson:** a focus rule on a page with several inputs is written as "restore what had focus", never "send focus to X".
- **Scanner-guard and keyboard users.** The guard blocks Enter / Space in any modal surface; the drawer needed a human-pace exception. It works, but it depends on keystroke timing (documented in CLAUDE.md).
- **A full Rust run was killed once at the memory cap** while another project's guarded job and the E2E stack were up; re-run after stopping the stack.
