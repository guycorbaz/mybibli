## 2. What went well

- **The copy was approved at planning** (epic D11). The stories implemented it word for word, and no review reopened it. 20-3's four open questions were answered in one message ("as recommended"). This is practice A3 applied at epic level, and it was the cheapest form of A3 seen so far.
- **Small, independent stories (Rule #24).** Five feature stories touched disjoint surfaces: wish list, series page, series form, location form, location tree. Each review pass came back clean except 20-2. The whole epic took one day, alongside epic 19.
- **Plain POST forms now refuse next to the field.** Series total in 20-3, location description in 20-4, the gap form in 20-2. Each has an E2E that submits the refused value and asserts the message (Rule #3, epic 17 A2).
- **A review finding became an app-wide rule.** 20-2 M3 (an accessible name not starting with its visible text, WCAG 2.5.3) and the same Low in 20-1 led to the lead's decision (#734). The rule is in CLAUDE.md, with a `starts_with` unit test per key, and the existing names were fixed in #746.
- **The tree is simpler and more honest.** It dropped an incomplete ARIA tree pattern (#700) for a nested list that screen readers handle natively. axe is scoped to the tree, and the page-wide "no tree role" check is kept.

## 3. What did not go well

- **An E2E helper matched English only** (`createChildLocation`, found at a re-run of 20-6). It looked for the parent's "Edit" link while another spec had left the shared librarian in French. The CLAUDE.md rule (EN and FR matchers) existed, but no check enforces it in `helpers/`. The same class of bug can sit in any helper until a spec happens to switch the language first.
- **A hidden coupling with epic 19.** 20-4's migration became "the newest migration" and broke `tests/backup_restore.rs` (19-8), which hard-coded it (aae1eedd). Rule #24 names couplings inside an epic. Two epics developed in parallel had no such list.
- **Stale binaries in local gates (#735).** Found while gating 20-4: the shared BuildKit cargo cache served a binary built from another worktree. Every gate since has rebuilt `--no-cache`.
- **An untranslated string survived the audit** (#737). The tree's "{n} vol" is built with `format!` in `routes/locations.rs`. The audit added in 19-1 checks attribute literals, not text in `format!` arguments. 20-5 rewrote the tree markup and did not see it either.
- **Two refusals stayed bare.** A version conflict on the series form still answers the bare 409 fragment (20-3 Q3 (a), #743). The location form shows only its own refusal on a 422, and a conflict after a refusal is a bare 409 (#732). Both were accepted by decision, but they are the same gap on two forms.
- **20-2's first pass found a disclosure.** `?wishlist_item=` built the success entry for anyone, so an anonymous visitor could read wish list titles by id (Medium, fixed: Librarian+ only, with a positive-shape note check). A query parameter that names a record was not in the story's threat check.
