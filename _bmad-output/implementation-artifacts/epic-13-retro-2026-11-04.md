## 2. What went well

- **Planned from real use, with evidence.** The production logs of the mass entry session gave exact causes for every complaint (label "already assigned" = three different scenarios; eight titles lost to Google Books 503s; ISBN-10s stored as UPC) before any story was written.
- **Independent review caught production-harming defects before any push:** 13-4's boot repair would have made every pending agent proposal on a converted comic stale (version bump) and re-decoded healthy text at every boot; 13-10's marker parser would have truncated "Symphonie n° 9", "Kill Bill Vol. 1" and omnibus titles; 13-3's re-fetch list lived only in memory; 13-2's queue could be blocked by one bad row.
- **Full-suite gates caught what targeted runs missed:** a 360 px overflow from the new date form (13-7), a cover spec picking the new Recent additions table (13-5), an escaping test broken by filing-time conversion (13-4).
- **The epic smoke test checked a design decision**: it showed that the web "added since" filter ignores an exact ISBN hit (recorded as intended in the 13-7 review).

## 3. What did not go well

- **The parser took four review rounds.** Each round found a new class of false positive (media types, double markers, bare-number ranges). The fix that converged was switching from "reject known bad shapes" to "accept only known good shapes". **Lesson:** any heuristic that rewrites stored data starts from positive shapes and a large real-data probe, not from exclusions.
- **A product option was missed at decision time.** For #581 the project lead chose between "extend À contrôler" and "a distinct anomaly notion" without being told the CR #443 labels already existed; the decision was revised mid-epic. **Lesson:** before asking a product question, list the existing features that already cover part of it.
- **Infrastructure noise:** one Docker Hub registry error (13-11 wizard job, re-run), one silent `cargo test` run that produced no results (memory pressure; re-run), the known flaky shelving undo test (#499) once.
- **Rule #12 debt grew slightly** (catalog.rs 3 226, titles.rs 2 782) despite new logic going to new modules → #597.
