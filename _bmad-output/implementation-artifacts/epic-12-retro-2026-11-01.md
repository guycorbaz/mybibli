## 2. What went well

- **Planned from real use.** Every story came from something the project lead hit on 2026-10-30 (stale proposals, an agent repeating mybibli's own lookups, the list leading to the title page, title spelling corrections refused). The UX and product decisions (#542, #535, #560, #561) were taken with him before coding, so no story was reworked for intent.
- **Review loops caught real defects before CI**: in 12-2, dropping the version check would have removed protections the per-field checks did not cover (cut baselines, re-identified titles, same-URL cover uploads, back-to-back cover acceptances) — all restored before the push.
- **The epic smoke test paid for itself**: its first CI run failed on a genuine deadlock no per-story test could see.
- **Pace**: the seven stories landed in about a day and a half of wall-clock, mostly CI waits.

## 3. What did not go well

- **A deadlock reached a story branch** (12-5's carry-forward `UPDATE … JOIN proposals WHERE status='pending'` share-locked every pending proposal through `idx_proposals_status`; 12-2's cover-race read had the same shape). Three review rounds discussed lock *order* but not lock *scope*. Fixed in #571 with a deterministic regression test (fails 1205 without the fix). **Lesson:** any locking or multi-table write on `proposals` must start from `idx_proposal_items_target` (or a PK list) — added to the action items.
- **Workstation memory**: systemd-oomd killed processes on the shared station (a kesh gate, Firefox; a `memguard-mybibli` scope on 2026-10-30). The project lead's rules (free ≥ 8 GB before any heavy command, one heavy command at a time, `mem-guard` everywhere including LaTeX) were adopted mid-epic; earlier in the epic E2E resets sometimes overlapped other work.
- **Docker disk growth**: each E2E reset leaves ~30 GB of volumes/images; 1 624 Docker volumes (45 GB reclaimable) at the last count. Not cleaned — deleting volumes is irreversible and may hit other projects (question Q3).
- **`cargo fmt`** reformats ~146 files on this machine (rustfmt 1.10); one accidental run had to be undone hunk by hunk (memory note added). Same as epic-11 action A5, still undecided.
