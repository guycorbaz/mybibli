## 2. What went well

- **Diagnosis from production logs.** #696 was quantified before any code (≈ 1 200–2 200 hits a day, ≈ 1 000 of 1 110 `slow statement` warnings, pool timeouts), so the fix targeted the cause (row inserts) and not the symptom.
- **Each root cause got a guard, not just a fix.** `tests/tailwind_sources.rs` fails the next time a Tailwind source is not copied into the image; `tests/cookieless_requests.rs` drives the whole router and pins the layer order and the "no row" property.
- **The full E2E run earned its cost.** Shipping the Rust-built classes in the image revealed two accessibility defects (contrast, `aria-required-parent`) that had been invisible because the classes never reached the image.
- **Recovery after the crash** was clean: integrity check, rebuild on Rust 1.99.1, test database recreated, gates re-run; nothing was lost but a log in `/tmp`.
- **Patch released and deployed the same day as requested.**

## 3. What did not go well

- **#695 shipped in the image unseen by every E2E run:** Playwright's `toBeVisible` counts `opacity: 0` as visible, and local builds (automatic source detection) and the image (only what the `css` stage copies) generated different CSS. A local-only check could not see it.
- **#696 lived 11 days in production** (since 2026-11-07) before it was noticed by reading logs by hand; nothing watches `slow statement` warnings or pool timeouts.
- **hotfix-696 took six review passes, and the design oscillated.** Pass 1 introduced a redirect to `/login?next=` for cookieless state-changing requests; passes 2–3 refined it; pass 4 showed it loses unsaved text, drops `no-store` and lets a cross-site `Referer` choose `next=` — the standard 403 refusal was restored. The user-visible behaviour of a refusal was a product choice made inside review loops.
- **hotfix-695 took four passes**, mostly on ARIA (expansion state added, then moved to the toggle) — scope creeping from "make the buttons visible" toward the tree pattern, stopped by filing #700.
- **The Rust-built HTML escapes the template audit.** The tree's delete button still uses `hx-confirm=` and English `aria-label`s (#698, medium), because `templates_audit` scans `templates/` only.
- **Rule #19 still misses surfaces:** the manual's env-var table and `website/roadmap.html`'s "current release" sentence were stale; caught by reading, not by a grep.
